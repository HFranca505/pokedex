# Minha Pokédex

Projeto desenvolvido em React JS para consultar e visualizar informações sobre Pokémon utilizando a PokéAPI.

## Funcionalidades

- Listagem de Pokémon.
- Pesquisa por nome.
- Filtro por tipo.
- Carregamento de mais Pokémon.
- Visualização de detalhes, como altura, peso, habilidades e atributos.
- Indicador de carregamento.
- Mensagem de erro caso não seja possível carregar os dados.
- Layout responsivo para celulares e computadores.

## Tecnologias utilizadas

- React JS
- JavaScript
- HTML
- CSS
- PokéAPI
- Vite

## Como executar o projeto

1. Clone ou baixe este repositório.
2. Abra a pasta do projeto no VS Code.
3. Abra o terminal.
4. Instale as dependências:

```bash
npm install
```

5. Execute o projeto:

```bash
npm run dev
```

6. Abra no navegador o endereço informado pelo Vite, geralmente `http://localhost:5173`.

## API utilizada

O projeto utiliza a [PokéAPI](https://pokeapi.co/) para buscar os dados dos Pokémon, seus tipos, imagens, habilidades e atributos.
